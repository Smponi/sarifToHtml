What still needs to happen before publishing

Wir muessen eine Lizenz waehlen und als LICENSE einchecken. Sinnvolle Kandidaten waeren MIT oder Apache-2.0.

Module path

Vor dem ersten Release sollte go.mod auf den finalen Repository-Pfad zeigen, zum Beispiel github.com/<owner>/sarif-html.
