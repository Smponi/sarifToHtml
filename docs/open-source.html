Publishing

What still needs to happen before publishing

The prototype works, but a useful open-source project needs more than a functioning binary path. This page keeps the remaining publishing decisions visible.

License

Choose a license and commit it as LICENSE. MIT and Apache-2.0 are both reasonable candidates for this kind of CLI.

Module path

Before the first release, go.mod should point at the final repository path, for example github.com/<owner>/sarif-html.

Releases

Keep the tag, changelog, cross-platform binary, and checksum process predictable for users who install the tool in CI.

Next Steps

  • Add LICENSE after choosing the license.
  • Keep the release workflow ready for cross-platform binaries.
  • Maintain CHANGELOG.md from the first release onward.
  • Add real SARIF fixtures for compatibility tests.
