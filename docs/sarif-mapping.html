Model

How a SARIF result becomes a finding

The internal model is intentionally smaller than SARIF itself. It focuses on tool, rule, location, and evidence data that reviewers need first in the generated report.

Details in the report

relatedLocations and codeFlows.threadFlows.locations are rendered as compact evidence lists. This matters for tools that report data flows or multiple affected code locations.

Source links

File links can be inferred from GitHub Actions or GitLab CI environment variables. For pull request and merge request edge cases, --source-url-template can point links at the exact ref that reviewers need.
