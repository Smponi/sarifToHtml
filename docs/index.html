Overview

What this docs folder is for

sarif-html soll aus SARIF 2.1.0 einen HTML-Report bauen, den Menschen gerne aufmachen. Diese Docs sind der Ort fuer Architekturentscheidungen, Mapping-Details, CLI-Verhalten und Teststrategie, ohne README-Overflow oder Tool-spezifisches Durcheinander.

Architecture

Wie Parser, internes Finding-Modell und HTML-Renderer zusammenspielen und wo spaeter weitere Output-Formate andocken koennen.

CLI surface

Welche Flags der Prototyp schon anbietet, wie mehrere Inputs gemerged werden und wie Source-Links sowie Fail-Thresholds funktionieren.

Testing

Welche Kernpfade bereits abgesichert sind und welche echten SARIF-Fixtures wir als naechstes fuer mehr Sicherheit ergaenzen sollten.

Open Source

Was vor dem Publishen noch entschieden werden muss: Lizenz, Modulpfad, Release-Prozess und Community-Dateien.
