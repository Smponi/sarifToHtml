Usage

Small surface, predictable behavior

The prototype already accepts multiple inputs, writes self-contained HTML with the default template, supports custom templates, and can fail a CI build with exit code 2 after still writing the report artifact.

Basic Usage

sarif-html input.sarif --out report.html

Multiple Inputs

sarif-html detekt.sarif semgrep.sarif codeql.sarif --out report.html

Source Links

sarif-html input.sarif \
  --repo-url https://github.com/acme/project \
  --revision abc123 \
  --out report.html

For GitLab, the link builder automatically uses /-/blob/. For GitHub and most other repository URLs it uses /blob/. In GitHub Actions and GitLab CI, sarif-html can infer these values from standard environment variables.

Source URL Templates

sarif-html input.sarif \
  --revision "$GITHUB_SHA" \
  --source-url-template "https://github.com/acme/project/blob/{revision}/{path}{lineFragment}" \
  --out report.html

Source URL templates are useful in pull request and merge request pipelines where the correct ref is not always a static branch. Supported placeholders include {path}, {pathRaw}, {line}, {revision}, and {lineFragment}.

Snippet Hydration

sarif-html reports/*.sarif \
  --source-root . \
  --source-root fixtures/scan-targets/go-bad \
  --out report.html

When a SARIF result has a file path and line number but no embedded snippet, sarif-html can read the relevant source line from the configured source roots. Relative paths are only read below those roots.

Custom HTML Templates

sarif-html reports/*.sarif \
  --template .github/sarif-html/report.tmpl \
  --out report.html \
  --fail-on error

Without --template, sarif-html uses the embedded default template. Custom templates are Go html/template files or directories containing .tmpl, .gotmpl, or .html files. They receive the versioned sarif-html.template.v1 data contract documented in Templates v1.

CI Gates

sarif-html input.sarif --out report.html --fail-on error
FlagDescription
--outOutput file. Use - to write HTML to stdout.
--titleReport title.
--templateCustom Go html/template file or template directory. Uses the embedded default template when omitted.
--repo-urlRepository base URL for clickable source links.
--revisionBranch, tag, or commit used for clickable source links.
--source-url-templateExplicit source URL template. Overrides automatic link generation.
--source-rootLocal source directory used to hydrate missing snippets. May be repeated.
--fail-onExit with code 2 when a finding reaches the threshold: error, warning, note, or none.
--versionPrint the CLI version.
