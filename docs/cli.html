Usage

Small surface, predictable behavior

Der Prototyp akzeptiert schon heute mehrere Inputs, schreibt self-contained HTML und kann auf Wunsch den Build mit Exit-Code 2 brechen, wenn eine Severity-Schwelle erreicht wird.

Basis

sarif-html input.sarif --out report.html

Mehrere Inputs

sarif-html detekt.sarif semgrep.sarif codeql.sarif --out report.html

Source-Links

sarif-html input.sarif \
  --repo-url https://github.com/acme/project \
  --revision abc123 \
  --out report.html

Fuer GitLab verwendet der Link-Builder automatisch /-/blob/, fuer GitHub und andere Repository-URLs /blob/. In GitHub Actions und GitLab CI kann sarif-html diese Werte aus den Standard-Umgebungsvariablen ableiten.

Source-Link-Templates

sarif-html input.sarif \
  --revision "$GITHUB_SHA" \
  --source-url-template "https://github.com/acme/project/blob/{revision}/{path}{lineFragment}" \
  --out report.html

Templates sind fuer Pull-Request- und Merge-Request-Kontexte gedacht, in denen der passende Ref nicht immer ein statischer Branch ist. Unterstuetzt werden unter anderem {path}, {pathRaw}, {line}, {revision} und {lineFragment}.

Snippets nachladen

sarif-html reports/*.sarif \
  --source-root . \
  --source-root fixtures/scan-targets/go-bad \
  --out report.html

Wenn ein SARIF-Resultat Datei und Zeile, aber keinen eingebetteten Snippet enthaelt, liest sarif-html die entsprechende Source-Zeile aus den angegebenen Source-Roots nach. Relative Pfade werden nur unterhalb dieser Roots gelesen.

CI-Gates

sarif-html input.sarif --out report.html --fail-on error
FlagBeschreibung
--outAusgabedatei. Mit - wird HTML auf stdout geschrieben.
--titleTitel im Report.
--repo-urlRepository-Basis-URL fuer klickbare Dateilinks.
--revisionBranch, Tag oder Commit fuer klickbare Dateilinks.
--source-url-templateExplizites Template fuer Dateilinks. Ueberschreibt die automatische Link-Erzeugung.
--source-rootLokales Source-Verzeichnis zum Nachladen fehlender Snippets. Kann mehrfach angegeben werden.
--fail-onExit-Code 2, wenn ein Finding die Schwelle erreicht: error, warning, note, none.
--versionGibt die CLI-Version aus.
